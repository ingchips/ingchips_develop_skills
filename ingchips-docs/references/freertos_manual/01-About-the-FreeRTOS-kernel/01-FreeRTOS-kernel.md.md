# The FreeRTOS™ Kernel

[Market leading](https://www.embedded.com/wp-content/uploads/2019/11/EETimes_Embedded_2019_Embedded_Markets_Study.pdf), 
de facto standard, and cross platform [RTOS](https://www.freertos.org/Documentation/01-FreeRTOS-quick-start/01-Beginners-guide/01-RTOS-fundamentals) 
kernel

Developed in partnership with the world's leading chip companies over a 18 year period, FreeRTOS is a 
market-leading real-time operating system for microcontrollers and small microprocessors. Distributed 
freely under the MIT open source license, FreeRTOS includes a kernel and a growing set of libraries 
suitable for use across all industry sectors. With one download every 170 seconds, FreeRTOS is built with an 
emphasis on reliability, accessibility, and ease of use.
