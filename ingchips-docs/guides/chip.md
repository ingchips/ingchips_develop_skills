# 芯片问题

先区分系列与具体料号；封装、引脚、电气极限和存储容量必须落实到料号。跨系列比较分别检索两本外设手册，不从共有 API 推断相同硬件能力。

| 所问内容 | 优先证据 | 检索词 |
|---|---|---|
| 外设能力、数量、寄存器 | 对应 `pg_ing916` / `pg_ing918` / `pg_ing20` | 外设名称、overview、features |
| SDK 架构、平台包、内存划分 | `user_guide`，中文补充 `user_guide_cn` | platform、memory、bundle、平台 |
| 开发板、引脚连接、常见问题 | `site_docs`，再核对对应芯片手册 | 板卡型号、FAQ、pin |
| 版本新增功能与修复 | `blog`，指定 SDK 的版本说明 | 精确版本号、功能名 |

某功能是否支持，要区分芯片硬件、协议栈平台包和 SDK 暴露的接口。引脚复用与板上连线也要分别核实。

纯 PDF 的电气规格、原理图或参考设计可能未收录；查不到时明确资料缺口并提供已知来源，不能用类似型号补全数值。源快照不证明是最新发布版。

建议输出：直接结论＋适用料号/版本＋证据。选型比较仅比较用户关心的条件，证据不足的格子写“待核实”。
